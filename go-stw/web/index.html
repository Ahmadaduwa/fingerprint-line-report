📌 ขั้นตอนเชื่อมต่อ Webhook ใน LINE Developers Console:
  1. เปิด LINE Developers Console แล้วเลือก Channel ของคุณ
  2. ไปที่แท็บ Messaging API เลื่อนลงมาที่หัวข้อ Webhook settings
  3. นำ URL นี้ไปใส่: กำลังโหลด... (คลิกเพื่อก็อปปี้)
  4. กดปุ่ม Update แล้วเปิดสวิตช์ Use webhook ให้เป็นสีเขียว
  5. ไปที่ LINE Official Account Manager > ตั้งค่า > ตั้งค่าการตอบกลับ > ปิด Auto-response messages เพื่อไม่ให้บอทพื้นฐานตอบซ้ำซ้อน
