============================================================
  STW_TeacherCheck (Go Edition สำหรับ Windows 7 32-bit / 64-bit)
============================================================

จุดเด่น:
- ไม่ต้องติดตั้ง Python
- ไม่ต้องอัปเดต Windows 7
- ไม่ต้องสร้างไฟล์ .env (ตั้งค่า Token/Secret ผ่านหน้าเว็บได้เลย)
- ไฟล์เดียวจบ พร้อม Web UI พอร์ต 8090 ในตัว
- รองรับระบบเพิ่มทุกคนที่แอดเพื่อน (Auto-Add) เข้าเป็นผู้รับรายงานอัตโนมัติทันที

------------------------------------------------------------
วิธีใช้งาน (เลือกได้ 2 แบบ):
------------------------------------------------------------

แบบที่ 1: รันดูหน้าจอสดๆ (แนะนำตอนทดสอบครั้งแรก)
- ดับเบิลคลิกที่ไฟล์: STW_TeacherCheck.exe
- จะมีหน้าต่างคอนโซลแสดงการทำงานขึ้นมา
- เปิดเบราว์เซอร์เข้าหน้าเว็บ: http://localhost:8090
  (User: admin / Pass: admin1234)

แบบที่ 2: ตั้งให้รันอัตโนมัติในเบื้องหลังทุกครั้งที่เปิดเครื่อง
- คลิกขวาที่ไฟล์: install_autostart.bat -> เลือก "Run as administrator"
- โปรแกรมจะทำงานใน Background เงียบๆ ไม่มีหน้าต่างดำกวนใจ
- เมื่อเปิดเครื่องคอมพิวเตอร์ ระบบจะพร้อมส่ง LINE ทันที

------------------------------------------------------------
การตั้งค่าเชื่อมต่อ LINE แบบง่ายๆ ผ่านหน้าเว็บ:
------------------------------------------------------------
1. เปิดเบราว์เซอร์ไปที่ http://localhost:8090 แล้วล็อกอิน (admin / admin1234)
2. กดปุ่มสีเขียว "💬 เชื่อมต่อ LINE":
   - วาง Channel Access Token (Long-lived) ที่ได้จาก LINE Developers Console
   - วาง Channel Secret (เพื่อความปลอดภัยในการยืนยัน Webhook)
   - ตรวจดูว่าติ๊กถูกที่ "⚡ เพิ่มทุกคนที่แอดเพื่อนเข้าเป็นผู้รับรายงานอัตโนมัติ" แล้ว
   - กดปุ่ม "🔌 ทดสอบเชื่อมต่อ Token" -> หน้าเว็บจะแสดงชื่อบอทและรูปโปรไฟล์ทันที
   - กด "💾 บันทึกการเชื่อมต่อ LINE"

3. ตั้งค่า Webhook ใน LINE Developers Console (ทำครั้งเดียว):
   - ไปที่ Messaging API > Webhook settings
   - วาง URL: http://<IP_เครื่องคอมพิวเตอร์ของคุณ>:8090/webhook (กดคลิกก็อปปี้จากหน้าเว็บได้เลย)
   - กดปุ่ม Update และเปิดสวิตช์ "Use webhook" เป็นสีเขียว
   - ใน LINE Official Account Manager > ตั้งค่าการตอบกลับ > ปิด Auto-response messages

เมื่อคุณครูหรือกลุ่ม LINE กด "เพิ่มเพื่อน (Add Friend)" หรือดึงบอทเข้ากลุ่ม
ระบบจะบันทึกชื่อและลงทะเบียนเข้ารับรายงานประจำวัน 09:30 น. ให้อัตโนมัติทันที!

------------------------------------------------------------
การตั้งค่าฐานข้อมูล & เวลาทำงาน:
------------------------------------------------------------
1. กดปุ่ม "⚙️ ตั้งค่าระบบ":
   - เวลาตัดสาย: 07:30 น. (หลังเวลานี้ถือว่าสาย และคำนวณจำนวนนาทีที่สาย)
   - เวลา Auto Download ของ HIP: 09:00 น.
   - เวลาส่งสรุปเข้า LINE: 09:30 น.
   - ฐานข้อมูล: hiptime (เลือก Windows Authentication ไม่ต้องใส่รหัส sa)
2. กดปุ่ม "🔌 ทดสอบการเชื่อมต่อ Database ตอนนี้" เพื่อตรวจสอบสถานะ
3. หากเกิดข้อผิดพลาด ให้เลื่อนลงล่างสุดแล้วกด "📋 คัดลอก Log ทั้งหมด" ก๊อปปี้ส่งให้ทีมงานตรวจสอบได้ทันที
